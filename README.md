# short-drama-video

短剧 / 短视频学习与实验工作区（私有仓库）。

## 用途

跟网上音视频内容学习 **AI 编排（orchestration）生成短剧**：拆解别人的流程、工具链与提示策略，沉淀成自己的笔记、脚本草稿和可复现实验。

## 可放什么

- 课程 / 视频学习笔记（编排链路、模型与工具分工）
- 短剧选题、剧本与分镜草稿
- 素材与成片目录约定
- 小实验代码与提示词模板

## 说明

本仓库默认 **private**，仅所有者可见。公开作品集请用其他公开仓库。

不修改、不关联 `listing-ops-agent` 与 `interview-agent-qa`。
