# short-drama-video

短剧 / 短视频学习与实验工作区（私有仓库）。

## 用途

跟网上音视频内容学习 **AI 编排（orchestration）生成短剧**：拆解别人的流程、工具链与提示策略，沉淀成自己的笔记、脚本草稿和可复现实验。

## 示例分镜（美女舞蹈叙事）

原创示例脚本（借爆款节奏骨架，不抄袭成片文案）：

| 文件 | 一句话 |
|------|--------|
| [examples/01-rooftop-neon-dance.md](examples/01-rooftop-neon-dance.md) | 雨后霓虹天台：被嘲只会拍短视频的舞者，用一支舞定规则 |
| [examples/02-cafe-rain-dance-reveal.md](examples/02-cafe-rain-dance-reveal.md) | 雨窗咖啡馆：戴口罩让座的「路人」，揭面竟是全网找的原跳 |

每份含：标题 / 类型 / premise / 灵感说明 / 角色卡 / 逐镜分镜（景别·动作·对白·AI 视频 prompt）。

已生成样片（示例 01）：[examples/assets/rooftop-neon-dance/](examples/assets/rooftop-neon-dance/) — 首帧、尾帧、约 15s `rooftop-neon-dance-15s.mp4`。

## 可放什么

- 课程 / 视频学习笔记（编排链路、模型与工具分工）
- 短剧选题、剧本与分镜草稿
- 素材与成片目录约定
- 小实验代码与提示词模板
