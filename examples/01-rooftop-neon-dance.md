# 霓虹天台 · 她转身那一拍
**Rooftop Neon Dance**

| 字段 | 内容 |
|------|------|
| **Genre** | 都市夜色 / 叙事短剧 + 舞蹈高光 |
| **时长建议** | 约 45–60 秒（竖屏 9:16） |
| **一句话 premise** | 被嘲「只会拍短视频」的独立舞者，在雨后霓虹天台用一支舞证明：镜头里的她，从来不是配角。 |

## Inspiration（高阶模式，非抄袭）

参考常见爆款结构，**原创改写**：

- 前 2–3 秒强钩子（嘲讽台词 / 定格眼神）→ 中段冲突 → 舞蹈卡点爆发 → 收尾身份/态度反转
- Soft glam / 霓虹夜景竖屏：近景抬眼 → 肩颈 wave → 扭腰爆点 → 细节特写 → 定格眼神
- 身份反差（被低估 → 舞台掌控）+ Beat-drop open 思路：舞蹈最高潮可前置闪一下再回到叙事

> 文案与分镜均为原创示例，仅借「钩子—张力—舞蹈高光—悬念/态度收尾」的节奏骨架。

## 角色卡（生成时保持一致）

- **林夏（女主）**：约 25 岁东亚女性，长直黑发微湿，利落高马尾；银白短夹克 + 黑色高腰舞裤 + 白色运动鞋；妆容干净，眼神锋利带笑。
- **路人男（嘲讽者）**：约 28 岁，卫衣棒球帽，只出声/半身，不抢戏。
- **场景**：城市高楼天台，雨后积水倒映霓虹粉紫蓝，远处楼宇灯火；夜景，侧逆光 + 发丝光。

## 后期建议（编排用）

- BGM：低频 house / 暗色电子，鼓点与镜 04、05 对齐。
- 字幕：钩子句与「别眨眼」可做大字卡；其余 VO 小字。
- AI 生成注意：每镜 **单一主动作**；角色服装/发型描述复用本页角色卡；少做复杂手指特写。
