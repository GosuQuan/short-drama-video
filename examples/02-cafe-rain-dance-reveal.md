# 雨窗咖啡馆 · 耳机里的她
**Cafe Rain Dance Reveal**

| 字段 | 内容 |
|------|------|
| **Genre** | 都市甜虐轻喜 / 身份反转 + 舞蹈高光 |
| **时长建议** | 约 50–70 秒（竖屏 9:16） |
| **一句话 premise** | 雨天咖啡馆里，戴帽口罩的「普通女孩」被催着让座；耳机里熟悉的编舞响起——她起身，在落地窗前跳完那段全网找原跳的舞，摘下口罩：原来爆款舞者一直坐在你对面。 |

## Inspiration（高阶模式，非抄袭）

参考常见爆款结构，**原创改写**：

- Hidden identity / 反转揭示：前半压抑普通，后半舞蹈揭晓身份
- 前 3 秒冲突钩子（让座羞辱）→ 雨窗氛围 → 舞蹈爆发 → 摘口罩身份揭示 cliffhanger
- Soft glam + 自然窗光：近景眼神 → 中景律动 → 落地窗全身舞 → 特写摘罩收尾
- Beat-drop：可把「最强一拍转身」闪前 1 秒作冷开场，再切回叙事

> 文案与分镜均为原创示例；不复制任何已有短剧台词或编舞名称。

## 角色卡（生成时保持一致）

- **苏晚（女主）**：约 24 岁东亚女性；伪装态：米色风衣、棒球帽、浅色口罩、耳机；真身态：取下帽与口罩后是微卷长发、精致淡妆，内搭黑色修身针织 + 同色半身裙，腿部线条利落。
- **催促女客**：约 30 岁，羽绒服，语气不耐烦（半身/背影即可）。
- **场景**：临街咖啡馆，大雨敲窗，暖黄室内灯 vs 冷蓝雨街；落地窗有水珠与霓虹倒影。

## 后期建议（编排用）

- BGM：前半 lo-fi 雨声铺底，镜 04 起切电音/流行舞曲卡点。
- 字幕：让座羞辱句、揭面金句做大字；身份线索用小字或音效叮一下即可。
- AI 生成注意：伪装态 vs 真身态分镜复用同一五官描述；摘帽/摘罩拆成镜 06 单动作，避免一镜内太多手部细节。
